📌 Overview

Nexus is an AI-driven web application that helps users instantly assess their stroke risk. With a simple registration and login system, users can enter personal health details and receive an instant prediction report, including the probability of stroke. The platform is designed to be fast, private, and secure while providing downloadable PDF reports for further use.

✨ Features

🔐 Authentication System – Secure Register & Login

🤖 AI-Powered Prediction – Predicts stroke risk instantly

📊 Personalized Reports – Shows probability & prediction outcome

📥 PDF Download – Download your report instantly

🎨 Modern UI – Built with React + TailwindCSS

⚡ Fast Backend – Powered by FastAPI

🚀 Getting Started

Follow these steps to run the project locally:

1️⃣ Clone the Repository
git clone https://github.com/your-username/nexus-stroke-predictor.git
cd nexus-stroke-predictor

2️⃣ Run Backend (FastAPI)
uvicorn main:app --reload --port 8000

3️⃣ Install Frontend Dependencies
npm install
npm install @tailwindcss/vite --save-dev

4️⃣ Start Frontend
npm run dev


Now, open http://localhost:5173/ in your browser 🚀
